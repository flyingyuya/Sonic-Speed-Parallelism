# 双二阶滤波器：结构选择与条件数分析

> **一句话结论**：定点误差比预期大一个数量级时，**先怀疑结构条件数，再怀疑位宽**。
> 加位宽是最贵的修法；换结构往往免费。

---

## 1. 问题现象

一个 5 段均衡器，`f0 = 100 Hz, fs = 48 kHz`，采样率是频点的 480 倍。
用 18 bit 系数（Q2.16，分辨率 1.5e−5）实现，
在 20 Hz 处实测频响误差达 **1.4 dB**。

直觉上"18 位分辨率 1.5e−5，对音频足够了"，但实测差两个数量级。

---

## 2. 根因：DC 附近的相消（catastrophic cancellation）

低架滤波器的传递函数：

```
        b0 + b1 z^-1 + b2 z^-2
H(z) = ------------------------
        1 + a1 z^-1 + a2 z^-2
```

在 DC（z = 1）：
- 分子 `b0+b1+b2` = 2 − 2cos(w0) ≈ **w0²**
- 系数本身量级：|b| ~ 1~2

```
f0 = 100 Hz, fs = 48 kHz
w0 = 2π·100/48000 = 0.01309
w0² = 1.7e-4
```

**分子只有 1.7e−4，却由量级 2 的系数相减得到 —— 这是 ~14 位有效位的相消。**

系数量化误差 `δ ≈ 2^-17 = 7.6e-6`，三项相加后分子误差可达 `2.3e-5`，
**占有效值的 13%**。

而频响是比值 `N/D`，分母也有同样量级的相消和独立的误差 ——
两个小量的比值对误差极其敏感，于是误差被放大到 1.4 dB。

---

## 3. 量化：需要多少位才够

要让分子相对误差 < 1%，需要系数绝对误差 `δ` 满足：

```
3δ / w0² < 0.01   →   δ < 5.7e-7   →   需要约 21 位小数位
```

**用 18 位系数做 100 Hz 低架，物理上做不到。** 这不是实现问题。

---

## 4. 解法一：降阶（推荐，零成本）

一阶低架的分子**正比于 w0 而不是 w0²**：

```
        b0 + b1 z^-1
H(z) = --------------
        1 + a1 z^-1

DC:  分子 ≈ 2·V·t,  其中 t = tan(π·f0/fs) ≈ π·f0/fs ≈ w0/2
```

条件数好了 **w0 倍** —— 对 100 Hz 就是 **75 倍**。

### 一阶低架的设计公式

```python
def first_order_low_shelf(f0, fs, v):
    """低频增益 v（线性），高频增益 1，转折约在 f0。
    返回 (b0, b1, 0.0, a1, 0.0) —— 二阶结构下 b2=a2=0 即退化为一阶。
    """
    t = math.tan(math.pi * f0 / fs)
    p = (1.0 - t) / (1.0 + t)
    a1 = -p
    b0 = (v * (1.0 - p) + (1.0 + p)) / 2.0
    b1 = (v * (1.0 - p) - (1.0 + p)) / 2.0
    return (b0, b1, 0.0, a1, 0.0)
```

对应的高架：

```python
def first_order_high_shelf(f0, fs, v):
    t = math.tan(math.pi * f0 / fs)
    p = (1.0 - t) / (1.0 + t)
    a1 = -p
    b0 = ((1.0 - p) + v * (1.0 + p)) / 2.0
    b1 = ((1.0 - p) - v * (1.0 + p)) / 2.0
    return (b0, b1, 0.0, a1, 0.0)
```

### 关键收益：RTL 零改动

二阶双二阶的 DF2T 结构里，令 `b2 = a2 = 0`：

```
y[n]  = b0·x[n] + s1
s1'   = b1·x[n] - a1·y[n] + s2       ← s2 恒为 0，自然不参与
s2'   = b2·x[n] - a2·y[n] = 0
```

**同一份 RTL，同一套端口，只是系数表里填 0。** 不需要任何分支或新模块。

实测效果：1.4 dB → **0.09 dB**（改善 15 倍）。

---

## 5. 解法二：换成增益可控的结构

某些结构在高频端会引起系数越界，换结构比加位宽便宜：

| 频段 | 二阶高架 | 二阶 peaking |
| --- | --- | --- |
| 8 kHz @ fs=48k, +10 dB | `b0 = 2.12` → **超出 Q2.16** ✗ | `b0 = 1.55` ✓ |

原因：peaking 滤波器的 DC 与 Nyquist 增益**恰好都是 1**，
系数天然落回 [−2, 2)；而高架在近 Nyquist 处条件数变差，系数被推向 2 以上。

**5 段均衡器的实用组合：**

| 段 | 结构 | 理由 |
| --- | --- | --- |
| 最低段 (100 Hz) | **一阶低架** | 避开 w0² 相消 |
| 中段 (300 Hz ~ 3 kHz) | 二阶 peaking | 条件数好，增益可控 |
| 最高段 (8 kHz) | **二阶 peaking**（不用高架） | 避免系数越界 |

全表实测：105 组系数（5 段 × 21 档），`max|c| = 1.953`，无一项越界。

---

## 6. 解法三：多率（multirate）—— 治本但最复杂

在 `fs = 12 kHz` 上做 100 Hz 的滤波，`w0` 提高 4 倍，条件数改善 16 倍。

**代价**：需要半带/多相抽取与内插滤波器，多出两级滤波器设计和状态管理，
调试复杂度显著上升。

**判断**：只有当"最低频段仍然远低于采样率、且降阶/换结构都不够"时才用。
本项目的 5 段均衡器用降阶就解决了，不需要多率。

## 7. 频响评估的正确写法

```python
def response_db(table, freqs, fs=48000.0, fixed=True, CF=16):
    """fixed=True 时用定点系数评估。注意 a0 必须用同一标度！"""
    out = []
    for f in freqs:
        z = cmath.exp(-1j * 2.0 * math.pi * f / fs)
        h = complex(1.0, 0.0)
        for sec in table:
            c = [quant_coef(v) for v in sec] if fixed else list(sec)
            a0 = float(1 << CF) if fixed else 1.0     # ← 关键
            b0, b1, b2, a1, a2 = c
            h *= (b0 + b1*z + b2*z*z) / (a0 + a1*z + a2*z*z)
        out.append(20.0 * math.log10(max(abs(h), 1e-30)))
    return out
```

**漏乘 `a0` 会虚报出 −187 dB 的荒谬误差**（分母小了几万倍）。

### Sanity check

> 定点误差应随精度提高**单调下降**。
> 如果 32 bit 格式的误差反而比 18 bit 更大，一定是评估代码错了，不是设计问题。

## 8. 完整设计流程

```
1. 浮点设计滤波器系数（RBJ Audio EQ Cookbook 等）
   ↓
2. 检查系数范围是否超出目标 Q 格式
   （超了 → 换结构，不要急着加位宽）
   ↓
3. 若最差频段条件数差 → 降阶 / 换结构
   ↓
4. 定点量化 + 全频段频响对比，记录最大误差
   ↓
5. 误差达标（< 0.1 dB）→ 生成 ROM
   误差不达标 → 回到第 2 步（先换结构，再考虑加位宽）
   ↓
6. 写定点黄金模型 + 位级对拍
```

## 9. 常见错误清单

| 现象 | 可能原因 |
| --- | --- |
| 频响整体偏移几 dB | **系数被削顶**（Q 格式范围不够） |
| 低频误差特别大 | 低架结构在近 DC 处的 w0² 相消 |
| 高频系数越界 | 高架滤波器在近 Nyquist 处条件数差，换 peaking |
| 误差随精度提高而变大 | 评估代码写错（最常见：`a0` 没缩放） |
| 滤波器"完全没效果" | 系数 ROM 地址算错 / 装载 FSM 中途换档 |
| 某些增益档位正常、某些异常 | 只检查了部分增益档的系数范围 |
