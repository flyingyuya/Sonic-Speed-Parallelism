# 定点 DSP 算法设计

## 核心原则

**定点设计的第一步不是写 RTL，而是确定"这个算法需要多少位"，并用浮点参考验证定点确实够用。**

定点误差只有三个来源，每一个都必须能定量：

| 来源 | 典型量级 | 危害 |
| --- | --- | --- |
| **系数量化** | 取决于系数格式 | **频响整体偏移**（最危险，会被误判为"算法错"） |
| **数据量化** | 每 bit ≈ 6 dB SNR | 噪声底抬高 |
| **累加器舍入/饱和** | 每样本 ±0.5 LSB | 噪声底抬高；饱和会硬削波 |

**系数量化是三者中最容易翻车的**，因为它不产生噪声，而是**直接改变系统函数**。

## 一、Q 格式：必须区分"位宽"和"小数位"

> **最常见的致命误解**：把"18 bit 有符号"当成 Q1.17。

```
signed [W-1:0] 配比例 2^-F   →   表示范围 [ -2^(W-1-F) , +2^(W-1-F) )
```

| 写法 | W | F | 范围 | 分辨率 |
| --- | --- | --- | --- | --- |
| `Q0.17`（**常被误写成 Q1.17**） | 18 | 17 | **[−1, 1)** | 7.6e−6 |
| `Q1.16` | 18 | 16 | [−2, 2) | 1.5e−5 |
| `Q2.15` | 18 | 15 | [−4, 4) | 3.1e−5 |
| `Q4.23` | 28 | 23 | [−16, 16) | 1.2e−7 |

（**Qm.n** 表示 m 位整数位 + n 位小数位，总位宽 m+n+1）

### 真实踩坑：Q1.17 削顶毁掉整个滤波器

双二阶滤波器的 `b1`/`a1` 典型值就在 **−2 附近**（低架滤波器实测 −1.984）。
用比例 `2^-17` 时，−1.984 需要 19 位才能表示，被**饱和削顶到 −1.0**，
系统函数完全变了。

| 系数格式 | 范围 | 最大频响误差 | 是否削顶 |
| --- | --- | --- | --- |
| 比例 2⁻¹⁷ (Q0.17) | [−1, 1) | **7.0 dB** | 是（14/105 项越界） |
| **Q2.16** | [−2, 2) | **0.048 dB** | 否 |
| Q2.23 (25 bit) | [−2, 2) | 0.0008 dB | 否 |
| Q4.27 (32 bit) | [−8, 8) | 0.0001 dB | 否 |

**修法只是把比例从 `2^-17` 换成 `2^-16`，一位不动，误差从 7 dB 降到 0.05 dB。**

### 设计期强制检查

**任何系数表生成脚本都必须有范围断言，越界直接报错退出。**

```python
def check_coef_range(table, bits, frac):
    """返回 (上限, 越界项列表)。越界必须报错，不能静默饱和。"""
    limit = float(1 << (bits - 1)) / (1 << frac)
    bad = [(bi, k, c)
           for bi, sec in enumerate(table)
           for k, c in enumerate(sec)
           if not (-limit <= c < limit)]
    return limit, bad
```

```python
# 生成 ROM 前
lim, bad = check_coef_range(all_entries, bits=18, frac=16)
if bad:
    raise SystemExit("系数超出 Q2.16 范围 [-%g, %g)：%s" % (lim, lim, bad[:5]))
```

**为什么必须硬失败**：静默饱和会生成一个"看起来能编译、仿真也能跑、
但频响完全错"的 ROM，排查成本极高。

## 二、位宽匹配 DSP48E1

7 系列 DSP48E1 的乘法器是 **25 × 18**（A 口 25 位，B 口 18 位）。
两个操作数的分配决定了精度取舍：

| 方案 | 数据 | 系数 | DSP/乘法 | 适用 |
| --- | --- | --- | --- | --- |
| A | 24 bit（A 口） | 18 bit（B 口） | 1 | 系数精度够用（Q2.16 即可） |
| B | 18 bit（B 口） | 25 bit（A 口） | 1 | 系数需要高精度 |
| C | 24 bit 拆 18+6 | 25 bit | 2 | 两者都要 |

**本项目选 A**：24 bit 数据（Q1.23）× 18 bit 系数（Q2.16），
实测频响误差 0.048 dB —— 远低于人耳 0.3 dB 可闻阈值。

### 乘积标度与右移量

设数据 `Q(DW-DF).DF`、系数 `Q(CW-CF).CF`：

```
乘积的小数位 = DF + CF
要把乘积转回数据标度，右移量 = (DF + CF) - DF = CF
```

一旦推导出来就发现：**右移量恰好等于系数的小数位 `CF`**，与数据位宽无关。
这个结论让参数化非常干净：

```verilog
localparam integer SH = CF;                        // 右移量 = 系数小数位
localparam [AW-1:0] RND = {{(AW-1){1'b0}},1'b1} << (SH-1);  // 四舍五入偏置
```

## 三、舍入与饱和

### 四舍五入（不是截断）

```verilog
wire signed [AW-1:0] accr = acc + RND;      // 加半个 LSB
wire signed [AW-1:0] ysh  = accr >>> SH;    // 算术右移（对负数向下取整）
```

Verilog 的 `>>>` 对负数是**算术右移**，等价于 Python 的 `>>`（floor 语义），
所以 Python 黄金模型可以逐位对齐：

```python
y = sat24((acc + RND) >> SH)      # Python 的 >> 对负数就是 floor，语义一致
```

### 饱和而不是回绕

```verilog
localparam signed [DW-1:0] MAXV = {1'b0, {(DW-1){1'b1}}};
localparam signed [DW-1:0] MINV = {1'b1, {(DW-1){1'b0}}};
wire ovf_p = (ysh > MAXV);
wire ovf_n = (ysh < MINV);
wire signed [DW-1:0] yn = ovf_p ? MAXV : (ovf_n ? MINV : ysh[DW-1:0]);
```

**测试激励必须专门覆盖饱和分支**（送满量程方波/极值），否则这两个分支永远不被测到。

### 累加器宽度怎么定

```
乘积宽度 = DW + CW              （24 + 18 = 42）
一个状态最多累加 3 个乘积         → 44 位
再留几位余量                     → 48 位（AW = 48）
```

AW 只影响面积不影响正确性（只要不溢出），给宽一点是便宜的保险。

## 四、频响评估：一个几乎人人会踩的坑

**用定点系数算频响时，`a0` 必须用同一个比例，不能用 1.0。**

```python
# ✗ 错：a0 = 1，但 b 是定点整数 → 分母小了几万倍
H = (b0 + b1*z + b2*z*z) / (1 + a1*z + a2*z*z)

# ✓ 对：a0 也用定点比例
A0 = float(1 << CF)
H = (b0 + b1*z + b2*z*z) / (A0 + a1*z + a2*z*z)
```

**真实踩坑**：漏乘 `a0` 后虚报出 **−187 dB** 的荒谬误差，
差点误判"Q2.16 精度不够"，进而放弃了一个本来可用的方案。

**教训：黄金模型自己也要被验证。** 可用的 sanity check：
> 定点误差应随精度提高**单调下降**。若高精度格式反而误差更大，一定是评估代码错了。

## 五、滤波器结构选择：条件数比精度更重要

**同样的系数精度，不同结构的实际误差能差 40 倍。**

### 条件数差在哪

低架（low-shelf）滤波器的分子在 DC 附近正比于 `w0²`，
而系数本身量级是 1~2：

```
f0 = 100 Hz, fs = 48 kHz  →  w0 = 0.0131  →  w0² = 1.7e-4
```

分子只有 1.7e−4 量级，却由量级 2 的系数相减得到 ——
这是 **~14 位有效数字的相消**，18 位系数根本不够。实测最差误差 **1.4 dB**。

### 修法：换成条件数好的结构

| 频段 | 结构 | 条件数 | 实测误差 |
| --- | --- | --- | --- |
| 100 Hz（最低段） | 二阶低架 | 分子 ∝ w0² | **1.4 dB** ✗ |
| 100 Hz（最低段） | **一阶低架** | 分子 ∝ w0 | **0.09 dB** ✓ |
| 中频 1k/3k | 二阶 peaking | DC/Nyquist 增益恰为 1 | 0.0004 dB ✓ |
| 8 kHz（最高段） | 二阶高架 | b0 达 2.12，超出 Q2.16 | 越界 ✗ |
| 8 kHz（最高段） | **二阶 peaking** | 系数自然落回 [−2,2) | 0.0003 dB ✓ |

**关键收益：一阶滤波器不需要新结构。** 二阶双二阶令 `b2 = a2 = 0` 即退化为一阶，
**RTL 零改动**：

```verilog
// 一阶低架：低频增益 v，高频增益 1
// H(z) = (b0 + b1 z^-1) / (1 + a1 z^-1)
t = tan(pi * f0 / fs)
p = (1 - t) / (1 + t);   a1 = -p
b0 = (v*(1-p) + (1+p)) / 2
b1 = (v*(1-p) - (1+p)) / 2
return (b0, b1, 0.0, a1, 0.0)     // b2 = a2 = 0
```

### 结论提炼

> **当定点误差比预期大一个数量级时，先怀疑结构条件数，再怀疑位宽。**
> 加位宽是最贵的修法；换结构往往免费。

详细推导见 [references/biquad-structure-choice.md](references/biquad-structure-choice.md)。

## 六、验证流程

1. **浮点参考设计** —— 先用 `math`/`numpy` 算出理想频响，确认算法本身对
2. **定点量化** —— 按选定 Q 格式量化系数
3. **范围检查** —— 断言无越界（否则直接失败）
4. **频响对比** —— 浮点 vs 定点，**全频段扫描**，记录最大误差
5. **位级黄金模型** —— Python 逐位复刻 RTL 的舍入/饱和/移位
6. **RTL 对拍** —— testbench 与黄金模型 **逐位相等**（用 `!==`，不是阈值比较）

```python
# 第 4 步的输出长这样，一眼看出是否达标
freqs = [20, 50, 100, 300, 1000, 3000, 8000, 12000, 20000]
# 浮点(dB) :  +5.976  +5.537  +2.630  -2.880 ...
# 定点(dB) :  +6.000  +5.581  +2.678  -2.887 ...
# 最大定点误差: 0.0481 dB   (系数范围 |c| < 2, 满量程 1.9844)
```

**验收判据（本项目采用）：**

- [ ] 系数无越界（硬断言）
- [ ] 全频段（20 Hz ~ 20 kHz）频响最大误差 **< 0.1 dB**
- [ ] RTL 与黄金模型 **逐位一致**（0 个不符点）
- [ ] 测试激励覆盖饱和分支
- [ ] 资源占用符合手算值（DSP 个数 = 并行乘法器个数）

位级对齐的细节见 [references/q-format-and-rounding.md](references/q-format-and-rounding.md)。
